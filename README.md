# wstui

A simple Word Search TUI tool built with Rust and [Ratatui](https://ratatui.rs/).

## 🚀 Features

* Play and solve word search puzzles in the terminal
* Supports both **2D and 3D puzzle modes**
* Generate small, medium, and large puzzles
* Saving and loading puzzles

## 📦 Installation

You can install the latest published version via [Cargo](https://crates.io/crates/wstui):

```sh
cargo install wstui
```

## ▶️ Usage

```sh
wstui
```

## 🛠️ Build from Source

Clone the repo and build:

```sh
git clone https://github.com/jpatel2005/wstui.git
cd wstui
cargo build --release
```
